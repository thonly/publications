# Submitted PDFs

**What this folder is:** the exact PDF bytes submitted to an external, **immutable** prior-art venue —
one file per submission. It is an evidence folder, not a build output.

**Why it exists.** TDCommons postings *cannot be removed and cannot be versioned* ("Once a Work is
deposited in the repository, it may not be removed"). The markdown in the parent directory keeps
moving; the posting does not. Keeping the submitted bytes under git means we can always show what was
posted, and when — which the venue itself gives us no way to prove.

**The rule.** ⛔ Only PDFs that were actually submitted somewhere. This is *not* a place to build a PDF
of every paper: a PDF is a derived artefact, binaries do not delta-compress, and a repo that
accumulates regenerated renders is how `thonly/notes` reached 5 GB. One blob per submission, never
regenerated in place.

**Not canonical.** The markdown is the paper. These are dated snapshots of a render, in the same sense
the external posting is — see `project_roadmap_backlog` A168 (*the fifth surface is a dated snapshot*).

**The `.packet.txt` beside each PDF is the submitted METADATA** — title, inventor, licence and, above
all, **the abstract**, which is a separate form field and therefore exists in no other file we hold.
The PDF does not contain it. Without the packet there would be no record of what abstract was posted.
⛔ `.txt`, not `.md`, on purpose: these are not papers, and a `.md` here would fail the corpus
front-matter check the day that check learns to recurse.

**Generated by** `scripts/tdc-pdf.py <slug>` (converter `scripts/md2html.py`) + Chrome headless
print-to-PDF — it refuses to print if the render loses a word of the markdown (the word-multiset diff),
and refuses `--submitted` for a slug already submitted. ⭐ The cover carries the **first-publication
date**, the **Zenodo concept DOI** and the **timestamp line with its scope limit**, so an examiner can
cite the earlier date rather than the posting's. *The first two PDFs were built from a session
scratchpad, where the converter nearly vanished; file one's cover predates these lines and prints a
canonical URL form that is now a 301 on thonly.org.*
