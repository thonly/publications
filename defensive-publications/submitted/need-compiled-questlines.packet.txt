ABSTRACT   (250 words — limit 250; condensed from the paper's ## Abstract, claims 1-8, §4-§9; no new matter)
We specify a software agent that generates multi-step, real-world volunteer activity sequences for an individual or household exclusively by selecting, ordering and narrating entries already present in community need registries: posted help requests, commons sites awaiting care, pending gift deliveries, and contacts the household itself has named. The sequence data structure has no operation that creates a task; each task is a reference to a live registry entry, re-checked when it begins, and the operator authors no entry. Completing a task confers no points, badges, currency or reputation; the only reward is acknowledgment the beneficiary chooses to send through the ordinary peer-to-peer ledger. Help requests use a schema with no price, bounty or compensation field. Helpers leave each site before any thanks; a feedback channel opened by the task-completion event delivers beneficiary acknowledgment to the helpers days later. Every task runs under personal-safety monitoring with dead-man escalation to designated contacts; doorstep tasks are adult-only, a requester's location stays coarse until acceptance, and memorial and sacred sites are excluded. Sequences are generated only on user request, with no push notifications or consecutive-day counters. The success metric is the rate of later unprompted prosocial acts, held privately and never used for allocation. An extension lets delivery drones answer a personal-safety alarm as witnesses under six rules: alarm-triggered only, with no patrol or escort; video end-to-end encrypted to the user's family; represented as witness, not rescuer; flight only to the alarm-raiser's own coordinate; never a paid tier; rules fixed before any aircraft flies.
